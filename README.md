## ◈ ABOUT THE PROJECT

**SmartProperty AI** is a real estate analysis application developed using Python and Streamlit.

The project explores how data analysis and technology can make property price and rental information easier to understand through an interactive web experience.

## 🚀 GET STARTED

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project**

```bash
cd smartproperty-ai
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```
