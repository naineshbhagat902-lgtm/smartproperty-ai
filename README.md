 # SmartProperty AI

A beginner-friendly Streamlit project for property price and rental analysis.

## Files
- `app.py`: main web app
- `data/properties.csv`: illustrative sample listings
- `requirements.txt`: required Python packages

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy online
1. Upload this project to a GitHub repository.
2. Open https://share.streamlit.io/
3. Create an app, select your repository, branch, and `app.py`.
4. Deploy.

All property data in this starter project is illustrative, not verified market data.
