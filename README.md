## ✨ About the Project

**SmartProperty AI** is a real estate analysis project designed to make property price and rental analysis easier and more accessible.

The application uses Python and Streamlit to provide a simple web-based experience for exploring property-related information.

The main goal is to demonstrate how technology and data analysis can help people understand the real estate market.

## 🎯 Project Objectives

- Make property analysis easier to understand.
- Explore property prices and rental information.
- Build an interactive web application using Streamlit.
- Demonstrate practical applications of Python in real estate.

## 🛠️ Technology Stack

| Technology | Purpose                   |
| ---------- | ------------------------- |
| Python     | Core programming language |
| Streamlit  | Web application framework |
| Pandas     | Data handling             |

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project directory**

```bash
cd SmartProperty-AI
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

The application will open in your browser.

## 🚀 Deployment

This project is deployed using Streamlit Community Cloud.

To deploy your own version:

1. Upload the project to GitHub.
2. Visit [https://share.streamlit.io/](https://share.streamlit.io/)
3. Connect your GitHub repository.
4. Select the correct branch.
5. Choose `app.py` as the main file.
6. Click Deploy.
